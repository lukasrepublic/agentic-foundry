# Production-readiness checklist: SERVICE (blueprint: BLUEPRINT)

- [ ] SLOs and SLIs defined as code and validated
- [ ] Error-budget policy written
- [ ] Every alert links a runbook
- [ ] Dashboards and logs reachable by the on-call
- [ ] Rollback tested; progressive rollout plan names an abort condition
- [ ] Owner and on-call named in CODEOWNERS
- [ ] Capacity and cost reviewed
- [ ] Production changes use announce-before and report-after with a correlation id
