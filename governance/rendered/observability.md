# Governance: observability

Generated by `scripts/foundry_governance.py render`. Do not edit. Effective rules (kits + governance/local). Details live in the source files.

## FG-OBS-001 - OTel semantic conventions and owner-prefixed custom names

Telemetry MUST use OpenTelemetry semantic conventions where one exists. A custom attribute or metric name MUST carry the owning team prefix. The telemetry registry MUST pass the Weaver registry check.

- level 1, active
- applies to: `**`
- check: ci -> `governance/kits/observability/checks/weaver-registry-check.sh`

## FG-OBS-002 - Alert-rule hygiene

Prometheus alert and recording rules MUST pass pint lint in CI. Each alert SHOULD carry a severity label and a runbook annotation (the shipped pint config reports a missing one as a warning).

- level 1, active
- applies to: `**/*.rules.yaml`, `**/*.rules.yml`, `**/alerts/**`, `**/rules/**`
- check: ci -> `governance/kits/observability/checks/pint-ci.sh`

## FG-OBS-003 - The factory's own usage collection is declared

The factory's own usage collection MUST be declared: what is recorded, where it is written and how it is read. It MUST be read through the usage script only.

- level 1, active
- applies to: `**`
- check: declared -> `scripts/foundry_usage.py`
