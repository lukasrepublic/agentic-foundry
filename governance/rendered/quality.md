## FG-QA-004 - Flaky tests are quarantined with a record, never skipped

A flaky test MUST be quarantined with a record that names an owner, an issue, an entry date and an expiry date. Quarantine MUST NOT mean skip. The test still runs and its result is reported. An expired entry MUST be reported and MUST be fixed or removed.

## FG-QA-006 - Done means the Done-means command passes again on merged main

A fix is done only when it is re-measured. After a merge, the check the fix targets (the ticket's Done-means command) MUST be re-run on the merged main, and the ticket MUST NOT be marked done until that re-run passes. All of a tick's re-checks MUST be batched into one record PR. Items recorded as fixed MUST be re-audited before any formal run.
